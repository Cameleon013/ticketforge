# Contributing

Thanks for considering a contribution!

1. Open an issue before large changes so the approach can be discussed.
2. Use Node.js 20 or newer.
3. Run `npm test` before submitting a pull request.
4. Keep changes focused and include tests for bug fixes and new behavior.
5. Never commit bot tokens, secrets, user data, or production database files.

By submitting a contribution, you agree that it may be distributed under the
project's MIT license.
